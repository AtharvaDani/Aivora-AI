# 🚀 Aivora AI

Aivora AI is an AI-powered full-stack application that combines multiple AI features into one platform.

It provides:
- 💬 AI Chat Assistant
- 🎨 AI Image Generator
- 🍳 AI Recipe Generator

Built using React, Spring Boot, and Generative AI APIs.

---

## ✨ Features

### 💬 AI Chat Assistant
- Ask questions and get AI-generated responses.
- Powered by Groq LLM models.

### 🎨 AI Image Generator
- Generate images from text prompts.
- Uses AI image generation APIs.

### 🍳 AI Recipe Generator
- Generate customized recipes based on:
  - Ingredients
  - Cuisine type
  - Dietary preferences
